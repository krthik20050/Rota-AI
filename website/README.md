# Rota AI — Website

Marketing website for [Rota AI](https://rota.software), the free, open-source voice dictation app for Windows, macOS, and Linux.

Built with Next.js 16, React 19, Tailwind CSS 4, and Framer Motion 12.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Build

```bash
npm run build
```

## Deploy

Push to the `main` branch — Vercel auto-deploys to https://rota.software.

## Structure

```
src/app/           # Next.js App Router pages
src/components/    # React components
src/lib/           # Utilities & blog helpers
public/            # Static assets
blog/              # Blog markdown posts
```
